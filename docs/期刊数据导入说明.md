# 期刊数据导入说明（模板 / 字段映射 / 校验规则）

本文件对应 `docs/期刊基础信息模板.csv` 与 `docs/年度指标与分区模板.csv`，两份模板均为 UTF-8（含 BOM）+ CRLF，可直接用 Excel / WPS 打开编辑。

导入入口：`admin-journals.html`（管理员）→ 选择文件 → 预览 → 校验 → 确认导入。预览阶段只做校验与计数，不写库；确认后才写入，且全过程在单个事务内完成。

---

## 一、期刊基础信息模板

| 列名 | 必填 | 格式 | 落库字段 | 说明 |
|---|---|---|---|---|
| `title` | 是 | 文本，≤300 字符 | `journals.title` / `title_norm` | 刊名，以出版社官方英文名为准；`title_norm` 由系统自动规范化（小写、去标点、压缩空格） |
| `chinese_name` | 否 | 文本 | `journals.chinese_name` | 中文刊名；无权威译名时留空，不臆造 |
| `issn` | 建议 | `NNNN-NNNN`，可写 8 位纯数字或带连字符 | `journals.issn` / `issn_norm` | 系统统一归一为 `NNNN-NNNN`；不校验校验位（避免历史刊号误判），但导入后会出现在核验清单里 |
| `eissn` | 否 | 同上 | `journals.eissn` / `eissn_norm` | 电子刊号 |
| `publisher` | 否 | 文本 | `journals.publisher` | 出版社/学协会全称 |
| `official_url` | 否 | `https://` 开头 | `journals.official_url` | 期刊官网；无法确认时留空，**不要填写出版社首页或检索平台页** |
| `subjects` | 否 | 多值，用 `\|` 分隔 | `journals.subjects`（text[]）/ `subject`（逗号串） | 学科标签，如 `管理学\|运筹学`。系统同时支持 `、,，;；/` 作为分隔符 |
| `source_name` | 是 | 文本 | `journals.source_name` | 数据来源名称，如 `Crossref 期刊公开元数据`、`OpenAlex`、`出版社官网` |
| `source_url` | 是 | URL | `journals.source_url` | 可回溯到该条记录的具体来源地址 |
| `is_demo` | 否 | `true` / `false`，默认 `false` | `journals.is_demo` | 演示数据必须填 `true`，且 `source_name` 需标明“演示”；默认检索不返回演示数据 |

**去重规则（导入时自动执行）**：`issn_norm` 相等 或 `eissn_norm` 相等 或 `title_norm` 相等 → 判定为已存在，执行**更新**而不是新增。更新只覆盖有值的字段，空值不会把库里已有内容清空。

**模板未包含、导入函数当前不接收的字段**：`keywords`（关键词数组）、`alt_issns`（并列刊号）、`note`（备注）、`type`（期刊/年鉴等）。这些字段暂存于导出文件与候选清单，需要入库前先在后台补录，不要塞进 CSV 期待生效。

## 二、年度指标与分区模板

一行一条记录，靠 `record_type` 区分三类：

| `record_type` | 含义 | 落库位置 | 需要的列 |
|---|---|---|---|
| `metric` | 年度指标值（影响因子、CiteScore 等） | `journal_metrics` | `metric_type`、`metric_value`、`year`、`source_name` |
| `jcr` | JCR 分区 | `journal_quartiles`（`ranking_system='JCR'`） | `year`、`subject_category`、`quartile`，可选 `rank_position`、`total_journals` |
| `cas` | 中科院分区 | `journal_quartiles`（`ranking_system='CAS'`） | `year`（**必填，必须是该分区表实际发布的年度**）、`subject_category`、`quartile` |

列定义：

| 列名 | 必填 | 格式 | 说明 |
|---|---|---|---|
| `journal_ref` | 是 | ISSN 或刊名 | 优先按 ISSN 匹配；匹配不到时按规范化刊名匹配；`jcr` / `cas` 额外允许刊名模糊包含匹配 |
| `record_type` | 是 | `metric` / `jcr` / `cas` | 缺省按 `metric` 处理 |
| `year` | 是 | 1900–2100 的整数 | 指标年度 / 分区表年度。**不得用当前年份冒充未发布的历史数据** |
| `metric_type` | `metric` 必填 | `impact_factor` / `cite_score` / `other` | 其它指标一律用 `other`，并在报告中写明口径 |
| `metric_value` | `metric` 必填 | 数值，保留 4 位小数 | 不能为负 |
| `subject_category` | `jcr`/`cas` 建议 | 文本 | JCR 用学科全称（如 `MANAGEMENT`）；CAS 用大类名（如 `管理科学`） |
| `quartile` | `jcr`/`cas` 必填 | `Q1`–`Q4` | 大小写不敏感 |
| `rank_position` / `total_journals` | 否 | 整数 | 有排名数据时填写，用于展示“X/Y” |
| `source_name` | 是 | 文本 | 数据来源。**只有获得授权使用的商业数据库才可写 JCR / 中科院分区来源** |
| `source_url` | 否 | URL | 来源地址 |
| `verification_status` | 否 | `verified` / `unverified` / `demo` / `outdated` | 默认 `unverified`；只有人工核对过来源才可标 `verified`；`demo` 会自动置 `is_demo=true` |

**幂等性**：同一 `(journal_id, metric_type, metric_year, source_name)` 重复导入会更新而不是重复插入；数值完全一致时计入“跳过”。分区按 `(journal_id, ranking_system, ranking_year, subject_category)` 唯一。

## 三、校验与错误码

导入过程中单行失败不会中断整批，失败行会连同原始内容写入 `import_jobs.failures`，可在后台“导入历史”里查看。

| 错误码 | 含义 | 处理 |
|---|---|---|
| `E_TITLE_REQUIRED` | 刊名为空 | 补刊名 |
| `E_JOURNAL_REF_REQUIRED` | 缺 `journal_ref` | 补 ISSN 或刊名 |
| `E_JOURNAL_NOT_FOUND:xxx` | 指标行的期刊在库中不存在 | 先用基础信息模板导入该刊 |
| `E_BAD_YEAR` | 年份缺失或超出 1900–2100 | 修正年份 |
| `E_BAD_STATUS` | `verification_status` 非法 | 用四个允许值之一 |
| `E_BAD_METRIC_TYPE:xxx` | 指标类型非法 | 用 `impact_factor` / `cite_score` / `other` |
| `E_METRIC_VALUE_REQUIRED` | 指标值为空 | 补数值，或该行改用 `jcr`/`cas` |
| `E_BAD_VALUE` | 指标值为负 | 修正 |
| `E_BAD_QUARTILE` | 分区不是 Q1–Q4 | 修正 |
| `E_BAD_RECORD_TYPE:xxx` | `record_type` 非法 | 用 `metric` / `jcr` / `cas` |

## 四、数据纪律（本项目强制）

1. **影响因子与分区只能来自有权使用的真实来源**。未获授权时，该字段保持空值或 `unverified`，不得填入估算值、相似指标或“参考值”。
2. **不得把 OpenAlex 的 `2yr_mean_citedness` 当作影响因子**。它是篇均被引，口径不同，本项目不导入该指标。
3. **中科院分区必须记录实际年度**。不同年度分区结果会变化，不能一份数据套用多年。
4. **演示数据必须隔离**：`is_demo=true`、来源名标注“演示”，默认检索不返回；任何统计口径需说明是否包含演示数据。
5. **每条记录都要能追溯到来源与年份**，否则按 `unverified` 处理并在页面显示“暂无已核验数据”。
